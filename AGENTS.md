# Guidance for coding agents

Sendero is a public repository: never commit a keystore, a password, a token, a personal path or a commercial
recording. `npm run check` (typecheck, lint, tests, guards) must pass before any commit.

- Expo SDK 58, React Native 0.88, TypeScript. Install packages with `npx expo install <package>` so versions match
  the SDK; read the versioned Expo docs (`https://docs.expo.dev/versions/v58.0.0/`) instead of recalling APIs.
- Native libraries with fast release cycles are pinned to exact versions in `package.json` (VisionCamera, Nitro,
  fast-tflite); read their installed type definitions under `node_modules` for the API.
- The `android` folder is generated by `expo prebuild` and never committed; native changes go through config plugins
  (`plugins/`) and local Expo modules (`modules/`).
- Everything visible is drawn in one Skia canvas (`docs/architecture.md`).
- Repository text is English with no em-dash and no emoji; strings shown to visitors are Mexican Spanish.
- Every bundled third-party asset is listed in `ASSETS.md` with its source and licence.
- Build the APK with `scripts/build-apk.ps1` (or `.sh`); it is never built in CI.
